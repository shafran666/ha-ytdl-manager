# Changelog

All notable changes to YTDL Manager will be documented here.

## [1.0.0] - 2026-11-22

### Initial Public Release

- Dynamic video and audio quality selection.
- Video codec selection.
- Estimated download size.
- English subtitle support.
- Smart chapter detection from video metadata and descriptions.
- Optional chapter discovery in comments.
- Editable chapter names and timestamps.
- Chapter embedding into MKV.
- Download Manager with thumbnails and progress tracking.
- Download queue and queue reordering.
- Scheduled downloads.
- Automatic retry support.
- Cancel, Resume and Delete actions.
- Built-in folder browser.
- Light and dark themes.
- Home Assistant Ingress integration.
